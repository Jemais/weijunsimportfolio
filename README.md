# Wei Jun Sim — Game Design Portfolio

Live site: https://jemais.github.io/weijunsimportfolio/

## Editing your site

Everything you'd want to change is in **`content.js`**: your name, bio, photo, software, experience, games and contact links.

1. Open `content.js` on GitHub and click the pencil icon (Edit).
2. Change the text between the quote marks.
3. Click **Commit changes**. The live site updates in 1–2 minutes.

If the page shows a red bar saying content.js couldn't be read, the last edit is missing a quote mark or a comma.

## Adding pictures

1. Open the `images` folder, click **Add file → Upload files** and drop your pictures in.
2. In `content.js`, write the path, e.g. `photo: "images/me.jpg",` or `image: "images/lantern-drift.png",`

File names are case-sensitive: `Me.JPG` and `me.jpg` are different files.
Wide screenshots (16:10, about 1280×800) fit the game cards best; a portrait photo (4:5) fits the profile card.

## Files

- `index.html` — layout and styling (no need to edit)
- `content.js` — your content
- `images/` — your pictures
